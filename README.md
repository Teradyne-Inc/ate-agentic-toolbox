# Plugin marketplace

Discover plugins that connect AI coding assistants to tools and workflows.
The marketplace supports GitHub Copilot and Claude Code, starting with the
IG-XL Debug suite.

## Available plugins

| Product | What it provides |
| ------- | ---------------- |
| [IG-XL Debug](plugins/igxl-debug/README.md) | API lookup, evidence-first C# generation, live code execution, and program/flow inspection through three separately installed plugins. |

## Get started

1. Install a supported assistant. See [harness setup](docs/harness-setup.md).
2. Open the product guide above for its prerequisites, executable downloads,
   installation commands, and verification.

Installing a plugin registers its bundled skills and MCP configuration; it does
not install external executables or runtimes. Follow the selected product's
setup instructions before using its tools.
